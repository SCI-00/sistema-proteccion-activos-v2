# 🔒 Sistema de Protección de Activos

Sistema integral de gestión de protección de activos para SCI DE OCCIDENTE & Omnilife México.

## 📋 Descripción

Sistema desarrollado para Victor Manuel De La Torre, Gerente de Protección de Activos - Zona Sureste, que abarca la gestión de 20 CEDIS en 6 estados del sureste mexicano.

### Estados cubiertos:
- Campeche
- Quintana Roo
- Tabasco
- Chiapas
- Oaxaca
- Yucatán

### Pilares de protección:
- 🔒 Seguridad Patrimonial
- 🚨 Protección Civil
- 👷 Seguridad y Salud en el Trabajo (SST)

## 🚀 Tecnologías

### Backend
- FastAPI
- SQLAlchemy
- PostgreSQL
- JWT Authentication

### Frontend
- Streamlit
- Pandas
- Plotly

## 📦 Instalación Local

### Backend
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload
```

### Frontend
```bash
cd frontend
pip install -r requirements.txt
streamlit run app.py
```

## 🔐 Variables de Entorno

### Backend
```
DATABASE_URL=postgresql://user:password@host:port/database
SECRET_KEY=tu-clave-secreta
```

### Frontend
```
API_URL=http://localhost:8000/api
```
